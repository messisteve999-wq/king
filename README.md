King v0.1.0 (package com.steve.king)

Installation :
1. Copier les dossiers app/, settings.gradle, build.gradle dans le dépôt GitHub King.
2. Copier gradlew, gradlew.bat, gradle/ et le workflow .github/workflows/ depuis le dépôt P_STE (déjà compilé avec succès).
3. Ouvrir l'appli King : autoriser l'affichage par-dessus, accès aux notifications (voir « Autoriser les paramètres restreints »), contacts, puis Démarrer la bulle.
4. Mode : suggestions (affiche une réponse) ou auto (envoie la réponse via l'action « Répondre » de la notification).
